# 示例插件

这是随应用分发的示例插件，用来演示 Lave 的**插件协议 v2**。
在「插件」页点「安装示例插件」会把它复制到本机的插件目录，之后打开开关即可运行。

## 文件构成

| 文件 | 作用 |
| --- | --- |
| `plugin.json` | 插件清单：身份信息、入口文件、订阅的事件、**配置项声明** |
| `main.py` | 插件本体，也是协议参考实现（只依赖标准库） |

## 它做了什么

1. 启动后读取主进程下发的配置、上次的状态与数据目录，回 `ready` 完成握手；
2. 每收到一条群聊 / 单聊消息就在日志里记一行，并把累计条数持久化；
3. 消息以配置里的**触发前缀**（默认 `#hi`）开头时，请求主进程代发一句问候；
4. 收到 `shutdown` 时把统计写入自己的数据目录再退出。

## 改它

`plugin.json` 里的 `config` 数组决定了「插件」页上会出现哪些配置项。
改完清单后重新启动插件即可生效；运行中改配置会立刻下发 `config_update`，
插件不需要重启。

想从零写一个插件，看 `main.py` 顶部的协议说明就够；更完整的协议文档见仓库的
文档站（`docs-site/`）。
