# Lave 文档

**Lave** 是一个 QQ 机器人**移动客户端**：手机端直接连腾讯官方
[QQ 机器人开放平台](https://bot.q.qq.com/wiki/) 的 Gateway WebSocket 网关接收事件，
用官方 HTTP OpenAPI 发消息与上传富媒体，**不需要任何自建公网后端**。

本仓库只使用官方接口实现，不包含任何逆向协议、抓包、Hook 或模拟 QQ 客户端登录的方案。

## 它能做什么

| 能力 | 说明 |
| --- | --- |
| 多机器人管理 | 每台设备最多同时在线 3 个机器人，各自独立连接与事件流 |
| 接收与回复 | 群聊 @ 消息、单聊消息；被动回复与主动消息两种通道 |
| 消息面板 | 会话列表、完整消息时间线、图片预览、手动发送 |
| 内置命令 | `#help` / `#ping` / `#status`，且回复一律走 `msg_id` 被动回复 |
| 插件系统 | 独立 Python 子进程 + JSON 行协议，可声明配置、持久化状态、崩溃隔离 |
| 消息统计 | 首页展示累计与今日收发量，7 / 14 / 30 天折线图 |
| 后台保活 | 前台服务 + 唤醒锁 + 看门狗闹钟 + 开机自启，尽量不被系统冻结或回收 |

## 它做不到什么

这些是**平台或官方接口的硬限制**，不是实现取舍。写在最前面，省得你照着别处的教程白折腾：

- **iOS 不能跑插件**：`dart:io` 的 `Process.start` 在 iOS 上不可用，无法创建子进程。
- **Android 上插件只支持 arm64**：内置的 Python 运行时只打包了 `arm64-v8a`。
- **历史消息里没有图片**：官方附件 URL 带签名且会失效，落盘没有意义。
- **群里所有人的头像拿不到**：官方消息事件不返回头像，群会话只能用群图标占位。
- **被「强行停止」后无法自动恢复**：Android 会让应用进入 stopped 状态，
  任何自动拉起（含开机广播）都失效，只能由用户重新打开应用。
